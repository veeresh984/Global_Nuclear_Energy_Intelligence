# ⚛️ Global Nuclear Energy Intelligence Platform

A comprehensive Streamlit-powered analytics platform for exploring global nuclear energy production, renewable energy growth, carbon emissions, and decarbonisation performance from **1965–2025**.

---

## 🌍 Project Overview

The Global Nuclear Energy Intelligence Platform provides:

* Nuclear Energy Analytics
* Renewable Energy Intelligence
* Carbon Emissions Monitoring
* Decarbonisation Insights
* Country Benchmarking
* Sustainability Rankings
* AI-Powered Executive Insights
* Interactive Data Visualizations

The platform is designed for:

* Energy Analysts
* Sustainability Consultants
* Climate Researchers
* Policy Makers
* ESG Teams
* Investors
* Government Agencies

# ⚙️ Installation

Clone repository:

```bash
git clone https://github.com/yourusername/nuclear-energy-analytics.git

cd nuclear-energy-analytics
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Locally

```bash
streamlit run app.py
```

Application will be available at:

```text
http://localhost:8501
```

---

# ☁️ Deploy on Streamlit Cloud

Push repository to GitHub.

Then deploy using:

https://streamlit.io/cloud

Settings:

```text
Main File:
app.py
```

Deployment time:

```text
~2 Minutes
```
